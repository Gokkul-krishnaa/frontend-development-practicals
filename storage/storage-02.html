Retrieve and display data from localStorage.

Working Demonstration

View student-friendly code 
<input id="field" value="Hello"><button id="run">Save</button><button id="load">Load</button><div id="out"></div><script>run.onclick=()=>localStorage.setItem("labData",field.value);load.onclick=()=>out.textContent=localStorage.getItem("labData")||"No data"</script>
